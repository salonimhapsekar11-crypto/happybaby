## How it is organised

1. **Foundations:** the tokens. Colour, type, spacing, radius, elevation.
2. **Layout:** Flex and Container, the only two things a page needs to arrange content.
3. **Atoms:** the smallest pieces: Button, IconButton, Icon, Avatar, StarRating.
4. **Molecules:** pieces that combine atoms: AvatarStack, TrustBar, ProofRow, ReviewCard, ImageCard, Stepper, PhoneMockup.
5. **Use cases:** real sections of the landing page (hero, first 24 hours, how it works, reviews), each listing exactly which parts it is built from.

## Principles

- **Structure over looks.** Auto layout in Figma is flexbox in code. Every value is a variable in Figma and a token in code: no raw hex colours, pixel radii or spacing in components.
- **One purple action per view.** Purple 500 is the single primary action. Blue is only for a live state, such as an active step or a running timer.
- **Accessible by default.** WCAG AA contrast is checked for every colour pair in both themes, every story is scanned with axe, and every control has a visible focus ring.
- **One typeface.** Poppins, nothing else.
- **German first.** Placeholder copy is German, with brackets where a real fact still needs to be verified. No invented claims.
- **Parity is tested.** A script compares the tokens exported from Figma with the CSS in this repo, so the two cannot drift silently.
