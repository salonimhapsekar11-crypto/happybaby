# What is flexbox?

**Flexbox** is a way to lay out a row or a column of things. You give a parent `display: flex`, and its children line up along one direction, called the **main axis**. The direction across it is the **cross axis**. It is one-dimensional: for rows *and* columns at once, use CSS Grid.

> If you have used Figma auto layout, you already know flexbox. They are the same idea.

## Main axis and cross axis

<FlexDemo title="Row" code="flex-direction: row" gap="16" />
<FlexDemo title="Column" code="flex-direction: column" direction="column" gap="16" count={3} />

In a **row** the main axis runs left to right and the cross axis runs top to bottom. In a **column** they swap.

### 1. Gap: space between children

### 3. align: position on the cross axis
<FlexDemo title="center" code="align-items: center" align="center" />

### 4. wrap: continue on the next line
<FlexDemo title="wrap" code="flex-wrap: wrap" wrap gap="12" count={14} />

### 5. grow: fill the leftover space
A child with `flex: 1` takes all remaining space. This is Figma's **Fill container**. A child with no `flex` is **Hug contents**: it is as big as it needs to be.

## When to use flex, and when to use grid

- **Flex:** a nav bar, a button with an icon, a list of tags, a card's content stack. Content decides the size.
- **Grid:** the three review cards, a photo gallery. The layout decides the size, in rows and columns.

## Using it here

```tsx
import { Flex } from './components/Flex/Flex';

<Flex direction="column" gap="16">
  <h2>Titel</h2>
  <Flex gap="12" align="center" justify="between">
    <Avatar alt="" src={src} />
    <span>Name</span>
  </Flex>
</Flex>
```

`Flex` only accepts space tokens for `gap`, so every layout stays on the 4 px grid. See **Layout / Flex** for every prop, and **Layout / Container** for the page-width wrapper.
