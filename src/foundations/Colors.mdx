# Colors

Generated from the Figma variables (`Primitives`, `Alias`, `Alias Light`). Dark is the default theme and Light is prepared.
The semantic tables below show both themes side by side. The **Theme** switch in the toolbar changes the component stories (for example Button).

**Rules from the design system**

1. **Blue is only for a live state** (a running timer, playing audio). Never for a generic call to action, navigation or decoration.
2. **`purple/500` (attention) is the single primary action** in a view.
3. Everything else that is an action or surface uses **`purple/700`**.
4. Grays are for text. Black and white are foundations. Yellow and pink are small warm highlights.
5. **Components use semantic tokens only**, never primitives.
